# OnePieceChatbot

A starter full-stack project for a One Piece themed chatbot.

## Structure

- `backend/` – FastAPI service with chat endpoint and AI service stub.
- `frontend/` – Angular client with chat UI and backend API integration.

## Quick start

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run start
```
